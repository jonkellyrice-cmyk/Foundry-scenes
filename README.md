# Orphaned Sun — Foundry Scenes

Foundry VTT v13 content module for prebuilt **Orphaned Sun** scenes with map assets, walls, doors, dynamic lighting, and scene automation.

## Install

Paste the manifest URL into Foundry/Forge:

`https://raw.githubusercontent.com/jonkellyrice-cmyk/Foundry-scenes/main/module.json`

The module creates its bundled scenes automatically for the active GM the first time it is enabled in a world. Existing scenes are never overwritten automatically.
